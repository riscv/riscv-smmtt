= RISC-V Specification

This document describes Supervisor Domain Access Protection - RISC-V privileged architecture extension to support physical address space (memory and devices) isolation for more than one supervisor domain use cases for RISC-V platforms. Use cases may use supervisor domains to reduce the supervisor Trusted Computing Base (TCB), with differential access to memory and other platform resources e.g. Confidential Computing (CoVE), Security Services, Secure Devices etc.

= Dependencies

To build the document, you'll need the following tools installed on your system:

```
  Make
  asciiDoctor-pdf, asciidoctor-bibtex, asciidoctor-diagram and asciidoctor-mathematical
  Docker
```

= Cloning and Building the Document

This project uses submodules to include the RISC-V documentation toolchain. 

```
  git clone --recurse-submodules https://github.com/riscv/riscv-smmtt.git
  cd ./riscv-smmtt.git
  make
```

The PDF and HTML are written to `build/`. The PDF is named
`supervisor-domains-v<MAJOR>.<MINOR>-<YYYYMMDD>.pdf`, as the Architecture Review
Committee requires.

`VERSION`: The version of the specification being built. By default it is derived from the git tags by `scripts/release-info.sh`; an untagged build is named `<latest tag>-<commit>` and is a development build, not an ARC submission artifact. To build a specific version, for example `make VERSION=v0.9`. Versions are two-digit, `vMAJOR.MINOR`, and compare as decimals (`v0.8` is higher than `v0.61`).

`DATE`: The build date, `YYYY-MM-DD`; it defaults to today.

The revision remark and the Document State preface are generated from the version, so there is no `REVMARK` to set.
